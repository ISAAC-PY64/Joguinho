Adicione as artes PNG com fundo transparente nestas pastas, usando o ID da espécie cadastrado em src/data/creatures.js:

  public/assets/creatures/<id-da-especie>/normal.png
  public/assets/creatures/<id-da-especie>/big.png
  public/assets/creatures/<id-da-especie>/giga.png

Exemplo: public/assets/creatures/chicken/normal.png. Para Big e Giga, se não houver imagem própria, o jogo reutiliza normal.png. Se nenhuma imagem for encontrada, usa o emoji cadastrado.
